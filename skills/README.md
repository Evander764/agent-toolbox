# Skills

Reusable AI-agent skills live here.

Each skill should have its own folder:

```text
skills/<skill-name>/SKILL.md
```

Current skills:

- `team`: low-typing multi-agent coordination with `规划师`, `协调师`, `执行人`,
  and `审核官`.
- `think`: short `$think` second-brain skill for automatic Codex agent windows,
  strict judging, first-principles, entropy-aware, multi-agent adversarial
  reasoning, modular decomposition, and experiment design.
- `huawei-watch-app-builder`: complete development, UI/UX architecture,
  dual-layer signing, and automated wireless sideloading workflow for Huawei
  Lite Wearables (HUAWEI WATCH FIT 5, FIT 3/4, WATCH GT series).
